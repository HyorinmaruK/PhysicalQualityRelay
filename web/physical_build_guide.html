Bench test protocol

Run the phases in order. Do not start a phase until every test in the previous phase is PASS. Results are saved in this browser only (local storage) until you export them. Nothing here is pre-filled; NOT RUN is the default.

Yes: you must 3D print the test specimens. Everything else is optional.

The specimens are the "products" that move through the line, so they have to be printed. The track, carrier, chute and mounts can be printed too, but cardboard, foam board, or wood strips work just as well. The repository has STL files only for the specimens; it has no CAD for the carrier, rails, chute, or brackets yet.

Print settings

  • Material: white or light PLA (contrast with the dark vision pad). Print all 9 in one batch with the same printer, nozzle, and settings.
  • Orientation: flat on the bed, 6 mm side vertical, as the STL is exported. No supports needed.
  • Layer height 0.2 mm, 3–4 perimeters/walls, 20–40% infill.
  • No brim if you can avoid it. If you need one, remove it completely: it changes the measured width.
  • Do not scale the files. Turn off any "XY size compensation" you have not calibrated, or record its value.
  • Measure widths at mid-height, not at the bottom edge (first-layer "elephant's foot" makes the bottom wider).
  • Write printer, nozzle, material, layer height, and date in the run log notes. The printed size will differ from the CAD size; that difference is part of what you measure.
